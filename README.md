# 🦄 Power BI Unicorn Project

## Overview
An interactive Power BI dashboard analyzing unicorn startups worldwide.  
It highlights funding trends, valuation growth, and geographic distribution.

## Features
- KPIs: Total Unicorns, Average Valuation, Funding Rounds
- Interactive filters for industry, country, and funding stage
- Visualizations: Bar charts, maps, and trend lines
- Clean, professional layout for recruiters and collaborators

## Repository Structure
```
powerbi-unicorn-project/
├── pbix/UnicornProject.pbix       # Main Power BI file
├── data/sample_dataset.csv        # Optional dataset (if shareable)
├── images/unicorn_dashboard.png   # Dashboard screenshot
├── README.md                      # Documentation
└── .gitignore                     # Ignore temp/cache files
```

## How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/username/powerbi-unicorn-project.git
   ```
2. Open `pbix/UnicornProject.pbix` in **Power BI Desktop**.
3. Explore dashboards and apply filters.
